# 📒 Lista de Contactos - React + Vite

Bienvenido a **Lista de Contactos**, una aplicación desarrollada con **React** utilizando **Vite** como herramienta de construcción.

Este proyecto permite:

- ✅ Cargar contactos desde un archivo JSON
- ➕ Agregar nuevos contactos
- ⭐ Marcar contactos como favoritos
- 🗑 Eliminar contactos
- 🎨 Interfaz moderna con CSS personalizado

---

## 🚀 Tecnologías Utilizadas

- ⚛️ React
- ⚡ Vite
- 🎨 CSS3
- 📦 Node.js

---
